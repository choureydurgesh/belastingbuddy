# Contributing

Thanks for wanting to help! Issues and pull requests are welcome.

## Before you open a pull request

- Keep changes focused; one topic per pull request.
- `npm run typecheck && npm run lint && npm test` should pass. CI runs these plus the
  security checks described in [docs/LEARNING.md](docs/LEARNING.md).
